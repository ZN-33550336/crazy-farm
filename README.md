# 🌾 瘋狂農場 • 果實計算器

專為《蛋仔派對》瘋狂農場打造的免費、純前端 3D 果實售價與詞條加成試算工具（目前版本：**v5.0.0**）。

👉 **立即使用線上計算器**：[https://zn-33550336.github.io/crazy-farm/farm/](https://zn-33550336.github.io/crazy-farm/farm/)

---

## ✨ 主要特色

- **🍎 69 種果實完整收錄**
  - 內建全部 69 種果實圖示、滿重上限、價格係數與生長耗時資料。
  - 支援品階篩選（至臻／金色／紫色／藍色／綠色／灰色）與台灣／中國常見別名搜尋（如「火龍果」、「奇異果」、「櫻桃」、「馬鈴薯」等）。
- **🧮 精準雙向推算與詞條矩陣**
  - 重量（KG）與比率（%）即時雙向換算，最高支援輸入至小數後 6 位。
  - 完整支援品質、色彩、特殊、天氣與活動下架詞條之複合倍率計算，並內建詞條合成與互斥邏輯。
  - 提供「全選(流)」、「全選(瓷)」一鍵全選天氣詞條，以及自由拖曳的「排列詞條」自訂分類功能。
- **⏱️ 生長耗時逆推 & 全作物比較表**
  - 即時推算當前重量的總生長耗時與每 1% 所需時間。
  - 內建全作物價值對比表，可拖動重量拉條並依「品階」或「價值」排序。
- **🌌 全新 3D 宇宙宮殿 × 舊版介面自由切換**
  - 預設搭載 3D 宇宙宮殿、旋轉星系與極光背景；設定內可隨時切回「舊版介面」（量子天體球）。
  - 支援深色星穹／淺色晨曦雙主題、三檔 3D 畫質等級、獨立操作／詞條音效開關，以及電腦滑鼠／手機陀螺儀互動。
  - 連點左上角寶石 3 次或快速晃動手機／滑鼠可觸發專屬能量特效。
- **⚡ 跨裝置體驗與自動記憶**
  - 針對電腦、平板與手機自動調整最佳欄數，所有開關與偏好設定皆於本機自動記憶。
  - 採用輕量化 WebP 圖片與 Service Worker 本機快取，一般網頁版回訪即可秒開。
